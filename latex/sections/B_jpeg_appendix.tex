\section*{Appendix B. JPEG Quality Sweep (Q95/Q85/Q70)}
\label{app:jpeg}

The main-text robustness claim is restricted to JPEG quality~$Q{=}70$ versus clean ID AUC (Table~\ref{tab:jpeg}).
For completeness, Table~\ref{tab:jpeg-app} reports ID test AUCs under the same locked checkpoints when decoded RGB images are recompressed at $Q\in\{95,85,70\}$ before the shared resize/normalize stack.
Absolute changes relative to clean remain within $0.003$ across qualities for all listed models; we do \emph{not} reinterpret these rows as broad compression robustness beyond the evaluated settings.
